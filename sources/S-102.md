# OpenAI Agents SDK + 指南

## 核心主张

- Guardrails 作为输入/输出/工具各阶段验证——harness 层信任边界执行点（H10 的 agent 形态实例）。
- 单 agent 起步，仅必要时演进多 agent；内置 tracing。
