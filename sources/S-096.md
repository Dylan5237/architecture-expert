# STRIDE / 威胁建模

## 核心主张
- STRIDE 六类威胁分类法；数据流图 + 信任边界为核心建模原语。
- 威胁建模发生在设计阶段，随设计变更迭代。

## 争议/误用
- STRIDE 类别不完全正交（Tampering 与 Info Disclosure 重叠）；Microsoft 生态起源。
