# Evans — DDD

## 核心主张
- Bounded Context：模型只在显式边界内一致；边界内术语唯一。
- Ubiquitous Language；战略设计（Context Map、Anticorruption Layer 等）。
- 复杂性不是消灭而是「在心部」用深层模型驯服。

## 争议/误用
- 战术模式在简单 CRUD 系统上过度工程化；bounded context 粒度无客观判定标准；微服务社区「一服务一上下文」简化并非 Evans 本意。
