# GitHub 2018-10-21 网络分区

## 机制
- 43 秒网络分区触发 Orchestrator (Raft) 跨区 failover，东西海岸脑裂，MySQL binlog 不一致，24 小时降级与人工对账。

## 教训
- 自动 failover 的 blast radius；分区恢复后的数据一致性对账成本。split brain 实证。
