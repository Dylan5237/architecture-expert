# USE Method（公开配套）

## 核心主张
- 对所有资源逐一检查 Utilization / Saturation / Errors；saturation 常以队列长度/调度延迟体现。

## 争议/误用
- 只覆盖资源维度，不覆盖锁竞争与应用级队列。
