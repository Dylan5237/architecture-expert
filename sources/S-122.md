# Arrakis（OSDI 2014）

## 核心主张
- 传统内核中介 I/O 是为「强制进程隔离」；Arrakis 让应用直接访问虚拟化设备、多数 I/O 跳过内核，获 2–5× 延迟、9× 吞吐改善。
- **但隔离未取消而是下放硬件**（SR-IOV/IOMMU）——隔离成本转移而非放弃。

## Stage 5 改变的结果
- P-004 收窄：「隔离不理性」的真实形态是用另一种保证机制（硬件虚拟化、静态验证）替代进程边界，而非无条件接受大 blast radius；隔离单元的粒度应随替代性保证机制与成本模型变化，不默认进程边界。
