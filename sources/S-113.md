# FreeRTOS Kernel — Embedded/Edge 公开可验证官方来源

## 核心主张
- 实时内核而非完整 OS：抢占式优先级调度、任务/队列/信号量/互斥/软件定时器，内核仅少数 C 文件 + 每架构一个 port。
- 确定性优先：静态内存分配选项、无动态分配的运行模式——H3（有界执行）与 H9（受控复杂度）在硬资源约束下的形态。
- 调度/优先级语义是正确性的一部分（对照 S-091 Pathfinder 优先级反转）。

## 争议/误用
- 内核不含网络栈/文件系统/安全边界（由附加库提供）；SafeRTOS 才是 IEC 61508 认证路径——不得把 FreeRTOS 引用为功能安全认证证据。
