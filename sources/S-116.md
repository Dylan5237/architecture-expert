# Go GC Guide — Memory Limit

## 核心主张（修正版）
- Go 1.19 引入 GOMEMLIMIT/debug.SetMemoryLimit：**soft runtime memory limit/budget**——runtime 接近上限时 GC 更激进；**不是 hard process memory bound**。
- 官方警告：limit 无法 100% 消除 OOM，且不覆盖 mmap/CGO 内存。
- **GC 只解决 managed-heap reclamation**；不解决任务/会话/外部句柄/副作用/可变业务状态的语义生命周期归属。

## Stage 5 改变的结果
- P-001 收窄（维度特定）：GC 豁免仅限 managed-heap 回收维度；语义 ownership 不在豁免内。
- P-003 GOOD CASE：托管堆表面无界增长，实际由 runtime 软预算机制治理——评审不得报为无界违规。
