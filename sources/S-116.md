# Go GC Guide — Memory Limit

## 核心主张
- Go 1.19 引入 GOMEMLIMIT/debug.SetMemoryLimit：runtime 尊重软内存上限，接近上限时 GC 更激进；目的是避免容器 OOM-kill。
- 官方同时警告：limit 无法 100% 消除 OOM，且不覆盖 mmap/CGO 内存。

## Stage 5 改变的结果
- P-001 攻击 2（GC 豁免）：部分成立的精确边界——GC 免除「谁释放」，不免除「谁为总量负责」。
- P-003 GOOD CASE（H 向）：托管堆表面无界增长，实际由 runtime 预算机制封顶——评审不得把 GC 堆报为无界违规。
