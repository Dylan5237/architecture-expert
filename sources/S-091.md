# Mars Pathfinder 1997 — 优先级反转

## 机制
- 低优先级任务持总线 mutex，被中优先级任务抢占，阻塞高优先级总线任务 → watchdog 复位。
- 实际数据率高于任何测试值，暴露时序窗口；修复 = 开启 VxWorks mutex 的 priority inheritance。

## 教训
- 锁持有时间/优先级继承是有界性机制；「测试中未出现」不等于「不存在」。非 RTOS 语境套用 priority inheritance 语义不同。
