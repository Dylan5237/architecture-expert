# DDIA — 数据密集型系统综合教材

## 核心主张
- 三大关注：可靠性、可扩展性、可维护性。
- 复制与分区是 scale-out 的基础权衡；一致性光谱 read committed → serializable → linearizable。
- 分布式根本困难：故障检测、不可靠时钟、网络分区。
- linearizability 与 total order broadcast 等价于共识。
- stream processing / unbundled database。

## 争议/误用
- 对 exactly-once 只肯「effectively once (idempotence)」；对 2PC 成本与微服务乐观度被部分实践者批评。
