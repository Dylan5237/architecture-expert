# Reactive Streams 规范

## 核心主张
- 强制性非阻塞 backpressure：Subscriber 通过 request(n) 显式声明处理能力；Publisher 不得超发。
- 由有界缓冲实现避免 OOM；JDK9 内化为 java.util.concurrent.Flow。

## 误用警告
- 规范是互操作底层 API，不是应用层 API；backpressure 只在全链路各环节都实现时成立，任一环节 unbounded buffer 即破功。
