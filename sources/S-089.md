# libuv 设计文档

## 核心主张
- 事件驱动异步 I/O；I/O loop 绑定单线程且非线程安全；按平台选最优机制（epoll/kqueue/IOCP）。
- 文件 I/O 与 DNS 走线程池（无真正异步文件 API）——「异步文件 I/O」实为线程池模拟。
- loop 迭代的明确阶段结构。

## 备注
- 运行时执行模型的权威机制描述；RQ-C 的核心机制来源。
