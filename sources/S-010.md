# Fowler — Software Architecture Guide

## 核心主张
- 架构是「重要的、难以改变的决策」（引 Ralph Johnson）；重要性由变更成本度量。
- 好架构师最大化可逆性——让决策更晚做、更容易改。
- 架构应服务于可演进性而非一次性正确。

## 争议/误用
- 「难以改变」定义的循环性被批评；Fowler 承认定义有意保持模糊。
