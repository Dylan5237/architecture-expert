# Smith 2018 — 结构化并发纲领

## 核心主张
- 裸 go 语句之于并发如同 goto 之于控制流：破坏调用栈作为错误处理与资源清理框架的能力。
- 不变式：子任务不得比父作用域活得更久；nursery/task scope 是同步屏障。
- 应由运行时强制而非程序员自律。术语最早由 Martin Sústrik 2016 提出。

## 误用警告
- 全局后台 worker / fire-and-forget 守护任务需显式脱离 scope，不能一刀切。
