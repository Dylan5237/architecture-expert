# Release It! — 生产故障模式集

## 核心主张
- 稳定性是架构属性而非配置属性。
- Circuit Breaker / Bulkhead / Timeout / Fail Fast 的命名与系统化出处。
- 「Integration points 是 #1 可用性风险」；生产故障呈链式与级联特征。

## 争议/误用
- 模式源自 2000s 企业系统；云原生场景实现层已演化（Hystrix→Resilience4j）。
- 离线出版物；notes 基于目录与作者公开材料。
