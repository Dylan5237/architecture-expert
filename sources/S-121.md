# PEP 404 — Python 2.8 Un-release Schedule

## 核心主张（修正版，仅 PEP 404 支持）
- 正式宣告永不发布 Python 2.8：预期的兼容/演进路径被生态治理方显式拒绝。
- **本条仅支持「治理化的生态演进决策」这一主张**；不得泛化为「technical debt 自动授权 breaking change」。
- 先前混入的「What's New in Python 3.0」材料及依赖第二来源的 claim 已删除（未单独准入）。

## Stage 5 改变的结果
- P-008 例外条款的第二独立形态（语言/生态演进）：破兼容在治理化决策下合法。
