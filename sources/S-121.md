# PEP 404 / Python 3 故意不兼容

## 核心主张
- Python 3.0 官方自述为「首次故意向后不兼容的 Python 发布」；PEP 404 正式宣告永不发布 2.8，「完全向后兼容明确不在选项内」。
- 理由：技术负债阻碍演进；维护多版本是显著拖累。

## Stage 5 改变的结果
- P-008 例外条款的第二独立证据族（语言演进形态，与 RFC 7568 安全形态独立）：故意破兼容在权威治理下合法。
