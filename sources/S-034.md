# Berenson 1995

## 核心主张
- ANSI 现象定义（dirty/non-repeatable/phantom）歧义；异常化定义 A0–A5B。
- 定义 snapshot isolation 并指出其允许 write skew；ANSI SERIALIZABLE 与真正可串行化不等价。
