# Shopify — 模块化单体

## 核心主张
- 百万级商户规模上选择模块化单体而非微服务。
- 模块边界（组件化 + 公开 API + 依赖方向强制）在单体内实现；部署单元 ≠ 组织/领域边界。

## 争议/误用
- 单企业案例；Ruby/Rails 生态特定。
