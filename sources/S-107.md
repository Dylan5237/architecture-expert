# Local-First Software

## 核心主张
- 数据主副本在用户设备，云端仅作同步；离线可读写。
- 七个理想属性：fast / multi-device / offline / collaborative / longevity / privacy / user control；CRDT 为关键技术。

## 争议/误用
- CRDT 路线被后续实践者批评运维复杂；Local AI Tool 形态的理论基础。
