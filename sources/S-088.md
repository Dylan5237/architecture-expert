# Node.js — 不要阻塞事件循环

## 核心主张
- 规则：「每个客户端任一时刻的工作量必须小」；回调时间复杂度须受控。
- 同步 API（crypto/zlib/fs/child_process 同步版）不得在服务端使用；长任务 partition 或 offload Worker Pool。
- ReDoS 正则与 JSON DoS 是典型阻塞向量。

## 备注
- bounded execution（H3）的运行时实例：回调执行时间有界性。
