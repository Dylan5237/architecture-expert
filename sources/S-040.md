# Fowler — Event Sourcing

## 核心主张
- 事件日志为 source of truth；状态 = 事件回放；temporal query。
- event sourcing ≠ event-driven 的区分。

## 争议/误用
- 常被与消息驱动混淆套用；回放成本与 schema 演进是主要代价。
