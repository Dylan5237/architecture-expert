# Cloudflare 2019-07-02 全球中断

## 机制
- 单条 WAF 正则（灾难性回溯）全局同步推送，27 分钟全网 CPU≈100%。
- CPU 护栏在早前重构中被误删；SOP 允许非紧急规则无灰度全球上线。

## 教训
- 配置即部署；灰度 kill switch；regex 引擎复杂度保证。无界计算（H3）+ 全局故障域（H4）双重实证。
