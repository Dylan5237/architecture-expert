# GitHub Spec Kit

## 核心主张
- Spec-Driven Development：Spec → Plan → Tasks → Implement 四阶段；生成可审查中间 artifact。
- constitution.md 作为不可变 ground rules（架构约束的 agent-consumable 形式）；规格是 source of truth。
