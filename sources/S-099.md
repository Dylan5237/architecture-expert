# Anthropic — Context Engineering

## 核心主张
- Context engineering：策展有限 token 集合；「context rot」（token 增长导致性能下降）。
- 长时任务三技术：compaction、structured note-taking、sub-agent 架构。
- Just-in-time context：agent 持轻量引用运行时加载，替代前置全量加载。
