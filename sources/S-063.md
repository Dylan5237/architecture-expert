# Meta 2021 BGP 中断

## 机制
- 骨干容量审计命令误切断数据中心连接 → 自托管 DNS 按设计撤回 BGP 宣告 → DNS 不可解析放大为 ~6 小时全球中断；物理/远程访问受自身系统故障阻滞。

## 教训
- 防御机制自耦合成故障放大器（H4 反例形态）；恢复路径依赖被故障本身的资源。
