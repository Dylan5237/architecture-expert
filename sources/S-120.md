# RFC 7568 — SSLv3 弃用

## 核心主张（修正版）
- 「SSLv3 MUST NOT be used」；正式修订 RFC 5246 的兼容条款，以安全为由禁止兼容回退（prohibit fallback）。
- **本条仅作为「更高优先级的规范性安全要求显式覆盖兼容性要求」的特定证据**；不得泛化为「security debt 可以破兼容」的一般规则。

## Stage 5 改变的结果
- P-008 收窄：破兼容在更强要求（本例为规范性安全要求）显式主导时合法——这是「显式、治理化、带成本声明的决策」的权威先例，与候选 statement 一致。
