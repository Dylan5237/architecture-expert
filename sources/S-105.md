# Android 官方架构指南

## 核心主张
- 分层：UI layer（ViewModel + 单向数据流）/ domain layer（可选）/ data layer（repository）。
- 关注点分离、从模型驱动 UI、单一可信来源（SSOT）。

## 争议/误用
- 平台厂商利益（推动 Jetpack 采用）；「推荐架构」被部分社区批评为过度工程化样板。
