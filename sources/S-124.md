# The Linux Kernel Driver Interface（stable-api-nonsense）

## 核心主张（限定）
- Linux 内核**内部**接口被有意允许不稳定：协调一致的内部消费者可随演进同步修改，长期兼容是负担。
- 内核到 userspace 的 **syscall 接口是另一类**：稳定的外部 contract（「不破坏用户空间」）。
- **不得泛化为「所有内部 API 都应该不兼容」**——这是单一所有权/紧协调生态内的特定治理选择。

## Stage 5 改变的结果
- P-008 GOOD CASE（internal-consumer）：同一系统内，内部紧协调接口与外部独立消费接口合法地拥有完全不同的稳定性政策——「契约保护按消费方独立性分级」的一手证据。
