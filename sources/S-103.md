# 12-Factor Agents

## 核心主张
- 「80% 的墙」：原型可跑但生产质量达不到的设计原则。
- LLM 是无状态函数，输出质量几乎由输入质量决定——context engineering 优先。
- 拥有自己的 control flow / prompts / context window；反对魔法 agent loop。

- 作者为 HumanLayer 创始人（human-in-the-loop 产品立场）；社区材料无同行评审。
