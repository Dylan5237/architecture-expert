# USL（NEEDS_EVIDENCE 标记）

## 核心主张
- C(N) = N / (1 + σ(N−1) + κN(N−1))；concurrency / contention σ / coherency κ。
- κ>0 时吞吐 retrograde（加节点反而变慢）；Amdahl 是 κ=0 特例。

## 关键限定
- 1993 CMG 原始论文无公开可验证全文；以 Springer 2007 书籍为可引用锚点。
- 经验拟合而非第一性原理；外推失效；σ/κ 物理解读有学界争议。**不得作为 Mother Principle 唯一支撑**（review-queue RQ2-006）。
