# Amazon Builders' Library

## 核心主张
- Timeouts, retries, and backoff with jitter（Brooker）：token-bucket 重试配额、指数退避+抖动。
- Avoiding insurmountable queue backlogs：队列积压的优先级排空。
- shuffled sharding / cell-based architecture 限制 blast radius；constant work 模式。
- Avoiding fallback in distributed systems：fallback 放大故障的风险。

- AWS 官方叙述，无独立验证；作为工业实践证据使用。
