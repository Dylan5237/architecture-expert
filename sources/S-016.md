# C4 Model

## 核心主张
- 四个缩放层级：System Context → Container → Component → Code；一图一受众。
- 抽象优先、记法次之，不绑定 UML。
- 核心洞见：不同涉众需要不同抽象层，单一图无法服务所有人。

## 争议/误用
- 非形式化记法，无法机检一致性；组件级图维护成本高、易过时（diagram rot）。
