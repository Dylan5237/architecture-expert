# T-011 Least-Privilege Restriction

## Intent
Grant only the permissions/trust required for the duty at a relevant trust boundary, including agent tool/action authority.

## Mechanism
Least privilege (S-092); validation at trust boundaries (S-096). Capability tokens (V-016-C) are a mechanism family, not a promoted extra tactic (RQ3-004).

## Applies When
Untrusted input, multiple privilege levels, external integration, or agent action execution rights.

## Does Not Solve
Shared-resource cascades (T-010). Zero-trust as a universal in-process mandate. Total-damage upper bound.

## Failure Patterns Mitigated
FP-006.

## Principle Links
MP-005.

## Trade-offs
Operational friction; over-partitioning closed single-user systems is a false positive (GC-012).

## GOOD CASE / Misuse Boundary
GC-012.

## Evidence / Gaps
RQ3-004 capability platform instance; RQ2-008 vendor agent evidence.
