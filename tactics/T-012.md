# T-012 Explicit Compatibility Direction and Migration Path

## Intent
Keep independent-consumer contracts evolvable by declaring reader/writer compatibility direction and a migration path, including governed breaks.

## Mechanism
Schema/protocol evolution rules (S-044/S-045) plus explicit override/migration governance (S-120/S-121). Internal vs external stability may differ (S-124).

## Applies When
Independently evolving consumers.

## Does Not Solve
Internal module information hiding (MP-002). Universal backward compatibility. expand-contract is **not** this tactic (V-021-G / RQ3-006 NEEDS_EVIDENCE).

## Failure Patterns Mitigated
FP-008.

## Principle Links
MP-007. This is a tactic, not a restatement of the principle as “always compatible.”

## Trade-offs
Dual-running versions, coordination cost.
