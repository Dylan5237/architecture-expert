# T-007 Backpressure

## Intent
Propagate downstream processing capacity upstream as an explicit demand signal.

## Mechanism
Reactive Streams `request(n)` is the specification-level instance (S-090). Holds only if every stage is bounded; any unbounded buffer breaks it. Actor mailboxes are a counterexample of natural absence (S-081).

## Applies When
Streaming/pipelined stages that can signal remaining demand.

## Does Not Solve
Entry rejection (T-008). Admission yes/no without an upstream signal (T-006). Degradation of function (T-009). **Not flow control**: flow control is a broader related term, not an alias (V-008-E).

## Failure Patterns Mitigated
FP-010 when the whole chain implements it.

## Principle Links
MP-009.

## Trade-offs
Requires cooperative producers; cannot be assumed from “we have queues.”

## GOOD CASE / Misuse Boundary
Implicit unbounded buffering is not backpressure.

## Evidence / Gaps
S-090 normative for the spec instance; not a universal placement mandate.
