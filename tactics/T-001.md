# T-001 Supervised / Structured Lifecycle

## Intent
Make parent-scope ownership of child work a runtime-enforced structure so tasks cannot outlive their owner unnoticed.

## Mechanism
Nurseries/scopes/task groups join or cancel children before the parent exits (S-084..086). OTP supervisors own restart/cleanup of supervised processes (S-114).

## Applies When
Concurrent/async work that must not leak after context end.

## Does Not Solve
Resource quantity bounds (MP-003); state conflict semantics (MP-008); assumed ordering the model does not provide (MP-010). Does not require every process to be supervised (`spawn()` exists in Erlang).

## Failure Patterns Mitigated
FP-001.

## Principle Links
MP-001. Supervision is a compliant mechanism, not a universal invariant.

## Trade-offs
Ceremony; reduced fire-and-forget flexibility. Java StructuredTaskScope: RQ3-002.

## GOOD CASE / Misuse Boundary
GC-001. Treating GC as this tactic is misuse.

## Evidence / Gaps
S-084..086 one conceptual lineage; S-114 scoped realization.
