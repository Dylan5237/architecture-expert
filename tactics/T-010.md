# T-010 Scoped Failure-Domain Isolation

## Intent
Partition the system so a fault's blast radius stays inside an intended failure domain.

## Mechanism
Cut shared-resource/dependency propagation (pools, hosts, cells, hardware I/O domains). Granularity is a function of alternative guarantees and cost, not a default process boundary.

## Applies When
Shared bottlenecks, multi-tenant or high-cost failure paths.

## Does Not Solve
Privilege minimization (T-011 / D-05). Generic “split into processes.” Universal blast-radius measurement (RQ5-001).

## Failure Patterns Mitigated
FP-004, and FP-005 when the defense is decoupled from the failing resource.

## Principle Links
MP-004.

## Trade-offs
Isolation has capacity and operational cost; SQLite-class economics may refuse it (GC-005).

## GOOD CASE / Misuse Boundary
GC-005, GC-006 (dimension-specific hardware protection is not generic containment).

## Evidence / Gaps
RQ5-001. Do not treat S-122 as proof of all-dimension containment.
