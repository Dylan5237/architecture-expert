# MP-007 Contract Preservation

## Statement

存在 independent consumer 依赖的 contract（V-012-B）必须保持显式兼容方向（reader/writer 视角，V-013-A/B）与迁移路径；破兼容仅在更高优先级 security/correctness 要求或治理化协调迁移显式主导时合法。

## Mechanism

契约是跨边界协作的稳定点；破坏契约把变更成本强转嫁给所有交互方。

## Applies When

独立演进节奏的多方交互；内部紧协调接口的稳定性政策可合法不同（S-124）。

## Does Not Require / Non-Prescription

不强制 universal backward compatibility；不规定 expand-contract/semver。expand-contract（V-021-G）保持 NEEDS_EVIDENCE，不实例化为 tactic。

## GOOD CASE / Non-Violation Boundaries

- GC-009 治理化安全破除（S-120）
- GC-010 治理化生态演进（S-121）
- GC-011 Linux 内部不稳定 + syscall 稳定（S-124）

## Failure Patterns

- [FP-008](../failure-patterns/FP-008.md) Ungoverned Independent-Consumer Contract Break

## Tactics / operationalization

## Evidence Status

NORMATIVE + EMPIRICAL + CONTEXT_DEPENDENT。scope: 契约稳定性依赖独立消费方/治理存在；Linux 内部 API 是边界案例非普遍许可。concentration/gaps: 行为语义兼容可机检性 open。Desktop ABI 证据缺席（诚实标注）。

## Distinctions
