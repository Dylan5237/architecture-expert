# MP-003 Bounded Execution

## Statement

system/service（运行时角色义，V-002-C 限定）/stream 的 lifetime 可以 indefinite；但相关时，per-work execution/wait/retention time、retry、queue、concurrency、memory、fan-out 等维度需要 effective bound 或 governed policy。

## Mechanism

L=λW——固定容量下超载转化为积压与级联超时；无界维度在负载/故障下以资源耗尽形式失效。

## Applies When

共享资源、外部输入、异步工作、跨边界调用。隐含界（输入限定的批处理）与 runtime 软预算（GOMEMLIMIT 型）是合法形态。

## Does Not Require / Non-Prescription

不规定具体 timeout、配额或队列实现。不把程序总运行时当作必须有限。`service` 不是自动的网络部署单元。

## GOOD CASE / Non-Violation Boundaries

- GC-004 lifetime indefinite 但 per-work 有界的 daemon/流
- GC-002 软预算托管堆

- [FP-003](../failure-patterns/FP-003.md) Unbounded Per-Work Dimension
