# MP-008 State Authority & Conflict Semantics

## Statement

每类状态必须显式声明两个正交维度：write/state authority（V-003-D）与 conflict/consistency semantics（V-010 带义项后缀）；任一不清则并发/故障下状态结果不可判定。

## Mechanism

无裁决规则 → 冲突无定义解（lost update / write skew）；副本与权威漂移；多写形态的合并语义必须显式。

## Applies When

可变状态 +（并发写 或 多副本 或 缓存层）。single-writer 非必需（CRDT/显式合并语义合法）。

## Does Not Require / Non-Prescription

不强制 single writer；不规定 event sourcing / CQRS / CRDT。consistency 必须带 V-010 义项后缀。authority 此处是状态写权，不是 authorization 或 evidence authority tier。

## GOOD CASE / Non-Violation Boundaries

- GC-013 CRDT/local-first 多写（S-119/S-107）
- GC-014 append-only 无冲突域 / 只读派生视图
