# FP-008 Ungoverned Independent-Consumer Contract Break

## Failure Signature

A contract (V-012-B) relied on by independently evolving consumers changes incompatibly without an explicit compatibility direction (reader/writer, V-013-A/B) and without a governed higher-priority override or coordinated migration.

## Causal Mechanism

The contract is the stable collaboration point; breaking it involuntarily transfers cost/risk to all counterparties (S-044/S-045).

## Preconditions / Trigger

Independent consumer cadence. Internal single-owner interfaces are a different policy class (S-124).

## Amplification Path

Silent schema/behavior change fans out to every uncoordinated consumer.

## Observable Evidence

Old readers/writers fail after an undeclared incompatible change; no migration path.

## False Positives / GOOD CASES

- GC-009 governed security/correctness break (S-120)
- GC-010 governed ecosystem migration (S-121)
- GC-011 Linux internal API instability with stable external syscall contract (S-124)

## Consequences

Compatibility and correctness failures across the consumer set.

## Mitigation Tactics

T-012 Explicit Compatibility Direction and Migration Path. Not universal backward compatibility. Not expand-contract (NEEDS_EVIDENCE).

## Trade-offs / Scope

Does not apply automatically to tightly coordinated internal interfaces.

## Principle Links

MP-007. Distinct from MP-002 internal variation hiding.

## Evidence / Gaps

Behavior-semantic machine-checkability remains open. Desktop ABI evidence absent.
