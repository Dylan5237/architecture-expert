# FP-009 Undefined Authority or Conflict Semantics

## Failure Signature

A state class lacks an explicit write/state authority (V-003-D) or explicit conflict/consistency semantics (V-010 with sense suffix), so concurrent, replica, or cache writes have no defined resolution.

## Causal Mechanism

Without an adjudication rule, lost update / write skew / replica-cache drift are undefined rather than chosen (S-023, S-034, S-036).

## Preconditions / Trigger

Mutable state plus concurrent writers, replicas, or cache layers.

## Amplification Path

Each extra writer or cache hop increases undefined outcomes.

## Observable Evidence

Last-write-wins by accident; replica divergence with no merge rule; cache serving an undeclared consistency (cache) relative to source of truth.

## False Positives / GOOD CASES

- GC-013 CRDT/local-first multi-writer with declared merge (D-14)
- GC-014 append-only log / read-only derived view

## Consequences

Incorrect state; unreproducible conflict outcomes.

## Mitigation Tactics

T-013 Explicit Merge / Conflict Semantics. Single-writer is one option, not the principle.

## Trade-offs / Scope

Bare "consistency" is illegal; suffix required. Isolation (transaction) ≠ failure isolation.

## Principle Links

MP-008. An orphan writer with a clear log authority is MP-001, not this FP (D-06). Timing/order mismatch is MP-010 (D-09).

## Evidence / Gaps
