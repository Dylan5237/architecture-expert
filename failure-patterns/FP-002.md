# FP-002 Hidden Variation-Axis Leak

## Failure Signature

A reasonably identifiable volatile design decision is not hidden behind a stable boundary, so a later change to that decision forces uncoordinated or error-prone edits across dependents.

## Causal Mechanism

Information hiding around a change-decision reduces the set of units that must move together (S-001). When the decision leaks, dependents encode it and co-change.

## Preconditions / Trigger

A variation axis that could have been identified in advance; repeated change along that axis.

## Amplification Path

Each additional dependent encoding the decision increases coordinated-modification, verification, and release cost.

## Observable Evidence

The same conceptual change edits many modules that should have been clients of a stable interface.

## False Positives / GOOD CASES

- GC-003 exploration with unknown variation axes: no boundary obligation yet.
- GC-007 broad but coherent coordinated change: spread is not itself a violation (P-006 is a review signal, not this FP).

## Consequences

Evolvability loss; incorrect co-change; accidental coupling.

## Mitigation Tactics

None instantiated. The intervention is MP-002's boundary placement, not a named tactic file.

## Trade-offs / Scope

Wrong early abstraction can cost more than duplication; this FP applies only when the axis was reasonably identifiable.

## Principle Links

MP-002. Do not treat P-006 change amplification as the failure itself (D-03).

## Evidence / Gaps

Parnas/SAIP lineage plus S-109 independent empirical shape. RQ3-001 remains; not used to promote P-006.
