## Decision rationale (concise)

**Required property (S1):** every order mutation attributable + reconstructable for 7 years — an applicable AX-003 regulatory non-negotiable. Any option must *demonstrate* protection of it.

**Evidence baseline (S2):** The ADR text is CONFIRMED as what it *says* (one option, one straw-man alternative, no reversibility/cost analysis). The current mechanism's protection is CONFIRMED from CODE (append-only audit table written in the same transaction as the mutation; reconstruction tooling exists) + HISTORY (2026-03 regulatory audit passed, zero findings). The ADR's "audit for free / rebuild any state" claim is a GENERIC_KNOWLEDGE mechanism claim that is at best HYPOTHESIS for this system: event sourcing relocates audit cost into event schema versioning/upcasting, snapshot/rebuild machinery, retention governance, and actor-attribution designed into every event — none of which the ADR addresses, and no event-store technology is even named.

**S4 gate (checked before defect findings):**
- **GC-014** — append-only log + derived read models is a *legal* authority/conflict model. Event sourcing is therefore **not** an MP-008 violation and "no single writer / no conflict rule" is a false positive here. The findings below are about the *decision record*, not the pattern.
- **GC-007** — breadth alone (14 services) is not a defect; coordinated wide change of units sharing a decision can be healthy. F2 does not rest on breadth.
- **GC-010** — a governed coordinated migration is legal; the defect is that ADR-017 contains *no* governance, reversibility, or audit-continuity plan to qualify for that good case.

**Adjudication (S5):** The core defect is not "event sourcing is bad" — it is that the ADR justifies an effectively irreversible platform-wide migration with a benefit the confirmed evidence shows the current system *already delivers*, while dismissing the only alternative by taste ("boring but works") instead of by property analysis (AX-001/AX-004; Q-047/Q-049). No property is named that the current mechanism cannot protect. Additionally, the chosen option's protection of the non-negotiable is undemonstrated: the event stream becomes a 7-year independent-consumer contract (14 services + auditors) with no compatibility direction, no rollback path for historical audit continuity, and no cost estimate.

**KNOWLEDGE_DRIFT:** none. ADR-017 is proposed, not accepted, and makes no current-behavior claim that CODE/RUNTIME contradict; the conflict is premise-quality, adjudicated above.

**Minimum correction (to the decision, not code):** return ADR-017 for revision requiring (1) property-based re-adjudication of alternatives, including the narrower option of event-sourcing only the order lifecycle (or keeping the same-transaction audit table) — naming a property the current mechanism demonstrably cannot protect, if one exists; (2) reversibility analysis + dual-run audit reconciliation with rollback; (3) migration cost estimate; (4) 7-year event schema versioning/retention governance and actor-attribution requirement. Recommend the board not approve as-is next week; the eventual scoped-vs-status-quo choice may legitimately become an OWNER_TRADE_OFF *after* correction.

**Uncertainty:** whether a genuine property gap exists (e.g., a coming regulatory demand for arbitrary temporal replay) is UNKNOWN from this record — that is the decision-changing unknown, named in F1's refutation condition.
