id: H11-012
title: A disclosure export adapter
task_object: proposed public-record export adapter for additional attachment formats
requested_mode: AUTO
user_request: Review the new disclosure adapter before deployment. It makes exports available sooner and adds supported
  attachment formats for our external recipients.
project_evidence:
  product_intent: 'Accepted disclosure contract: an export is visible only after every included component has completed
    the approved personal-information review. All supported attachment formats remain available. Holding an export
    pending is allowed; permanently dropping attachments or allowing early unreviewed publication is not.'
  code: The adapter starts asynchronous attachment-review jobs, waits only for the main-text review, then assembles
    the main text with the raw attachment bytes and exposes the export download. Completed attachment reviews later
    replace those raw bytes inside the same export. Its publication check tests main-text completion only.
  test: A fixture delays an attachment-review job. The main text completes and a recipient downloads the export
    while its raw attachment still contains a synthetic personal address. That address is removed when the attachment
    job finishes.
  architecture_intent: 'The approved boundary is a complete export: format-specific adapters supply components,
    and the common review/publication stage governs recipient visibility. Publication must not depend on an assumed
    completion order between formats.'
  history: Attachment formats evolve through independent adapter updates. The new adapter moved assembly ahead of
    attachment completion; the old path assembled only reviewed components.
  config: Attachment jobs have an existing deadline and a parent owner. On deadline the export may remain pending
    or fail explicitly; the supplied policy does not allow publishing unchecked material.
  user_assertion: The change author says the parent owner and deadlines make late completion harmless, and suggests
    dropping slow formats if waiting affects latency.
constraints:
- The review concerns the adapter delta and recipient visibility, not a new document-processing platform.
- The recipient-facing download contract covers attachments as well as main text.
notes_for_runner: Fresh context. Use the frozen SUT and this case payload.
