id: H11-006
title: A scanner installation packet
task_object: proposed firmware rollout for handheld barcode scanners
requested_mode: AUTO
user_request: Review the firmware rollout for qualification. We can add a board-identity check locally; is that
  enough to approve the field installation?
project_evidence:
  product_intent: 'Accepted installation requirements: an incompatible board must never run the image, and any interrupted
    installation must boot either the old approved image or the complete new approved image. A service visit is
    not an accepted substitute for recoverable boot.'
  code: The installer checks the image digest but not board identity before programming the inactive image slot.
    The patch adds a board-identity comparison before programming. The boot-selection writer, reset handler and
    bootloader code are not included.
  test: A lab fixture loads an image for a different board without the proposed check and halts at startup. With
    the check, it is refused before programming. No power-interruption installation test is attached.
  architecture_intent: The design mentions two image slots. It does not state whether boot-selection writes are
    atomic, how interrupted programming is recognized, or which completed image reset selects.
  user_assertion: The rollout owner says two slots plus the new check guarantee recoverable boot in every interruption
    case.
constraints:
- Field qualification covers image compatibility and installation recovery.
- Field access to the scanner requires scheduled site visits.
notes_for_runner: Fresh context. Use the frozen SUT and this case payload.
